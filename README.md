# Snippet Vault Cloud

Deploy with Vercel + Supabase.

1. Create a Supabase project.
2. Run `supabase.sql` in SQL Editor.
3. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in Vercel Environment Variables.
4. Deploy this folder/repository with Vercel.

The frontend uses the public Supabase browser key. Do not expose a service-role/secret key.
